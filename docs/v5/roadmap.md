## Sentinel versions

Until the first release, Coolify uses Sentinel `main-<sha>` images, not
releases: `FLUX_IMAGE` and `constants.node.builder_image` pin `main-6774450`
by digest (Nodes 1 and 3 of the dev cluster run `sentinel-host` `main-6774450`). `upstream.json` takes only release versions, so a
new Node gets `sentinel-host` 1.1.7 from it. Such a Node has no
`image.build.target.v1`, no read lane for fast commands (Sentinel
`0d256e1`), no published ports (Sentinel `525e3be`), and no owner or mode of secret files (Sentinel `dd12f4d`), no Static builds (Sentinel `be0c977`), no Docker socket for stack services (Sentinel `b0a04a5`), no external image storage (Sentinel `8e040d0`), no `user:` for stack services (Sentinel `99c9629`), no image cleanup (Sentinel `5d8337f`), and no workload convergence in Sentinel (`workload.reconcile.v1`, Sentinel `6774450`). Install the `main-<sha>` `sentinel-host` on it by hand with
`InstallSentinel`.
