# Viewsjs

## One experimental badge, never in a sidebar
Mark a feature that is not stable yet only with `<x-experimental-badge />`, in the top right of its page. Never add another badge, icon, or variant, and never put it in a sidebar or menu. Svelte canvases use `ExperimentalBadge.svelte`.
