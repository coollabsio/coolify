Catppuccin, Gruvbox, One Dark, Rosé Pine, Solarized, and Tokyo Night presets, an iTerm2 `.itermcolors` import, and an instance default for the `Custom` theme of `Appearance`, an idea from Resetnak

- Import an iTerm2 color file, or paste its content into `Share code`, to fill the four colors
- Instance admins set the default theme in `Settings` > `Advanced` > `Default theme`. Users who did not choose a theme see it, and `Use instance default` in `Appearance` switches back to it
- Browsers that already saved a theme keep it, because earlier versions saved `Dark` for every user
