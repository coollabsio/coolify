`Submodules`, `Git LFS`, `Clone depth`, and `Watch paths` for cluster applications, and the same Git settings for Git stacks

- The `Git` settings are on the `General` page of a Git application and of a Git stack, and in the API. A preview uses the settings of its application
- `Watch paths` is on the `Webhooks` tab and in the API. A push or a preview skips the build only when the Git provider lists every changed file and no file matches
